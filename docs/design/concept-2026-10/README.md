# 2026-10 디자인 재검토 HTML 시안

2026-10-06~17에 디자인 시스템을 다시 탐색하며 만든 정적 HTML 시안이다. 사용자가 방향에 만족한 상태(2026-10-17)를 그대로 보존한다. 실제 앱으로 옮길 때 **느낌이 달라지지 않도록 값과 동작을 여기서 그대로 가져가는 기준 자료**다.

- 지위: 방향 확정 전의 시안. 구현 범위와 세부 결정은 별도 스펙에서 확정한다. 현행 규범은 여전히 [UI Guidelines](../../ui-guidelines.md)와 `app/globals.css`다.
- 상호작용 수준: 느낌을 판단하려고 만든 시연용이다. 키보드 조작·보조기기·예외 상태는 구현에서 스펙 기준으로 다시 갖춘다. 이 폴더의 코드를 그대로 붙여 넣지 않는다.
- 배포 방식: 새 디자인은 `redesign` 작업 브랜치에 쌓고 Vercel 브랜치 미리보기 주소에서 확인한 뒤, 완성되면 `main`에 **한 번에 머지**한다(2026-10-18 결정). 앱 안에 옛·새 화면을 고르는 스위치는 두지 않는다.

## 열어 보기

`app/fonts/`의 서체를 상대 경로로 읽으므로 **저장소 루트에서** 서버를 띄운다.

```sh
python3 -m http.server 8765
# http://127.0.0.1:8765/docs/design/concept-2026-10/index.html
```

책 표지(`img/`)는 저작물이라 공개 저장소에 올리지 않았다. 표지가 빈 칸으로 보이는 것이 정상이다. 로컬에 있으면 `img/`에 두면 된다(`.gitignore` 처리됨).

`?v=N` 쿼리는 캐시를 막는 정적 서버용 표시다. 의미 없다.

### 간지 묶음 동작 (`pile.js`)

- 보이는 자리 넷: 위 세 장 + 맨 아래 자리(가장 뒤의 장). 사이 장은 숨긴다.
- 자리 `SLOT=[[0,0],[16,15],[32,30],[48,45]]`, 숨긴 장 `MID=[40,37]`, 깊이별 기울기 배율 `TILT=[.22,.7,.85,1]`.
- 기울기는 종이마다 갖는다(1.3~3.2도, 바로 위 장과 반대). 뒤로 들어갈 때마다 새로 정한다.
- 넘김은 **한 번의 이어진 WAAPI 애니메이션 560ms**: 옆(오른쪽)으로 다음 장과 겹치지 않을 때까지 빠졌다가(최소 48px는 화면에 남김) 38% 지점에서 방향을 바꿔 뒤로 들어간다. 빠질 때 `cubic-bezier(.33,1,.68,1)`, 돌아올 때 `cubic-bezier(.65,0,.35,1)`. 순서(DOM)는 가장 멀리 빠진 순간에 바꾸고, 나머지 장은 300ms로 한 칸씩 올라온다.
- 손으로 밀기: 한계에 가까울수록 무거워지고, 한계의 45%를 넘기거나 속도 0.11px/ms 이상이면 넘긴다.
- 동작 줄이기: 이동 없이 순서만 바꾸고 160ms 흐림.
- 넘기는 동안 페이지가 옆으로 밀리지 않게 `html,body{overflow-x:clip}`.

React로 옮길 때 DOM 순서를 바꾸면 CSS transition이 끊긴다. 지금처럼 WAAPI 하나로 그리거나 순서를 상태로 두고 transform만 바꾼다.

## 하지 않기로 한 것

같은 안을 다시 제안하지 않는다.

- 기울어진 도장 박스, 물건을 픽셀로 그린 소품(리본·북다트·문진), 띠 모양 책 머리/옆면 그림
- 다음 장 머리를 탭 바 위에 걸쳐 보이기, 처음 한 번 살짝 올라오기 같은 스크롤 안내
- 덧붙인 생각이 그때의 생각을 덮는 배치, 의미 없는 아래 간지(두께 표현), 오늘 화면의 날짜 숫자 위 회상 간지
- 간지에 탭이 튀어나오거나 잘린 모양, 간지에 플래그 꽂기
- 간지 넘김을 아래로 빼기(옆으로 뺀다)
