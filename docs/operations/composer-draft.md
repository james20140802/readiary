# 홈에서 작성 중인 문장 이어 쓰기

홈 작성기는 책을 바꾸거나 같은 탭에서 다른 화면을 다녀와도 문장과 생각을 각각 유지한다. 작성기 안의 현재 책·변경 버튼으로 제목을 검색하고 선택한다. 후보는 선택기를 연 동안 20권씩 조회하며, 복원된 책이 홈 목록에 없으면 해당 책 한 권만 조회한다. 선택 해제·검색 실패·삭제된 책은 다른 책으로 조용히 대체하지 않고 다시 선택하도록 한다.

## 보관 범위

- 같은 탭의 `sessionStorage`에 계정 식별자, 선택한 책 ID, 문장, 생각, 입력 모드, 비공개 설정을 한 초안으로 보관한다. 본문 입력은 화면 이동 전 바로 기록한다.
- 새로고침도 복원하지만 탭 종료 후 복원·다른 기기 동기화는 보장하지 않는다. 브라우저의 세션 복구 동작에 따라 보관 기간이 달라질 수 있다.
- 저장 성공과 확인 후 초안 버리기, 로그아웃·계정 전환 때 정리한다. 서버가 늦게 응답하면 제출했던 초안과 일치할 때만 제거해 이후 작성한 초안을 보호한다.
- 인증 초기 이벤트에서 계정이 일치하기 전에는 초안을 표시하거나 입력·저장하지 않는다. 앱 셸은 작성기가 없는 화면에서도 인증 변경을 받아 초안을 정리한다.
- 저장 공간 차단·용량 오류가 나면 화면의 입력은 유지하고 보관 실패를 안내한다.
- 범위는 홈의 최초 저장 전 초안이다. 저장 후 덧붙이기, 별도 기록 등록·수정 폼은 이 저장소를 사용하지 않는다.

## 개인정보·데이터 경계

초안은 저장 행동 전 서버/API·분석 로그로 전송하지 않으며 DB나 Storage에 저장하지 않는다. 개인정보처리방침의 서버에 보관하는 독서 기록과 구별되는 탭 내 임시 입력이다. 화면에서 탭 보관 여부를 안내한다. PWA/Workbox 응답 캐시를 초안 저장에 사용하지 않는다.

책 후보 조회는 기존 Supabase 브라우저 클라이언트와 인증 세션·RLS를 사용하고 `user_id` 조건을 추가한다. 저장 API의 `getUser()`·책 소유권 확인과 기존 공개 범위 처리는 유지한다. `is_private=false`는 친구 열람 범위이며 초안 보관이 외부 공유를 만들지는 않는다. DB 마이그레이션·Storage 정책 변경은 없다.

- 문장/생각 독립 유지, 두 번째 페이지의 책 선택, 화면 언마운트·재마운트와 새로고침 복원, 비공개 설정 유지, 실패 시 입력 유지, 성공 후 초안 삭제, 계정 변경·로그아웃 비움 확인.

- 실제 인증·운영 DB 통합, iOS 설치형 PWA 실기기, 프로덕션 배포는 미검증이다. 로컬 대체 응답 검증을 실서비스 검증으로 보지 않는다.
